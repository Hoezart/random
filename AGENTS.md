# Archive Guard

This repository is an experimental archive, not an active product.

## Rules for agents

1. Do not add new product development here.
2. Do not promote historical prototype logic, thresholds, models, or visualizations as validated research.
3. Do not merge experimental branches into `main` unless the user explicitly decides to revive a specific prototype.
4. New durable projects belong in their own clearly named repository.
5. If salvaging an idea from an old branch, copy only the minimal useful concept into the appropriate maintained repository and preserve provenance.
