# Experimental Archive

This repository is an unmaintained prototype/archive workspace, not a production project.

The default branch intentionally contains no supported application or trading system. Historical experiment branches may contain incomplete prototypes created for exploration. Their code, models, thresholds, outputs, and visualizations should not be treated as validated research, financial advice, or production-ready software.

Current metals-market research is maintained separately under the private **Metals Lab** research stack, where hypotheses, data provenance, execution assumptions, out-of-sample validation, and promotion gates are tracked explicitly.
